# Miguel Torres — perfil profesional público

Sitio estático dentro del repositorio PRISMA_CV. En Vercel, el proyecto público debe usar `public/miguel` como raíz y no incluir las funciones API del dashboard.

## Funciones del sitio

- Tres versiones de posicionamiento profesional.
- Análisis local de términos de una convocatoria, sin enviar datos.
- Seguimiento de vacantes guardado en el navegador.
- Generación del CV con el diálogo de impresión del navegador.

## Despliegue

Vercel publica desde la rama `feature/miguel-public-profile`, con `public/miguel` como raíz, comando de compilación `echo Static profile: no build required` y directorio de salida `.`. Los nuevos commits de esta rama generan despliegues nuevos.

Confirma el contenido del CV, el correo visible y los enlaces antes de compartir la dirección pública. No añadas DNI, certificados ni expedientes al repositorio.
